# Agent 产品接入

Maa Verge 使用既有 LangChain／LangGraph TypeScript 与应用服务的 SQLite JSON/KV Store。模型、对话和执行协调均在固定 Bun 服务内，不引入 PowerContext、Python、另一套业务数据库或跨平台多 Agent 服务。自动解新关卡与视觉控制继续单独推进；本版 Agent 可以申请运行已保存的日常任务表、工具和已导入作业。

## 模型与凭据

在「设置 → 模型与 Agent → 模型连接」填写提供商、API 基础地址、模型名和可选 API 密钥，明确选择系统凭据存储或仅本次桌面会话，再点击「保存配置」一起提交。连接、用量提醒和单价均不自动保存；密钥留空时不修改已有凭据，失败时保留输入供重试。只请求 `POST /responses`，默认 `store:false`，不自动切换 Chat Completions，不自动重试付费请求。服务必须兼容 Responses 输出项、函数调用与本机历史回传；不兼容时明确停止。

模型请求固定使用 `stream:true`，供应商须返回 `text/event-stream`。应用增量解析 SSE 与 UTF-8 分片，通过 `agent.turn.get`／`agent.session.get` 的可选 `turn.progress` 返回临时正文及等待、生成、工具调用状态；界面按现有轮询逐步刷新，正文预览最多 64000 字符。预览只在内存中保留，不写入消息、checkpoint 或事件日志，也不作为下一轮上下文。摘要请求不展示正文预览。

只有收到 `response.completed` 且最终输出通过校验，才保存完整输出项、记录用量并继续工具调用。工具参数的 delta、参数 done 或输出项 done 均不单独授权执行；`phase`、调用 ID、最终不透明推理内容和供应商扩展字段原样保留。失败、取消、断流、`response.incomplete` 或缺少完成事件都会结束本次接收并清除预览，不把部分输出当作成功，不自动重试或切换 API。此前已提交的工具操作仍按业务账本核对。

每次模型请求的本机超时独立计时：从请求开始到首个非空响应体字节最多 120 秒（仅收到 HTTP 头不算首响应）；之后连续 120 秒没有非空响应体字节则判定流空闲超时，SSE 心跳也会重置空闲计时；从发起请求至完成事件总计最多 10 分钟。超时终止连接，并分别提示首响应、流空闲或总时长超时；用户取消与远端 HTTP 状态（包括 504）单独反馈。SSE 能让中间结果提早到达，但不保证消除供应商或中转链路的 504。不支持 SSE 的服务会明确报兼容性错误，不静默接收完整 JSON。

Rust 独占系统钥匙串访问，凭据绑定数据根、提供商及规范化地址。同一地址的模型名变化可以复用密钥；地址变化不会发送旧地址的密钥。公开接口只提供设置、状态和删除，没有读取密钥方法。桌面宿主通过已有子进程 stdio，在开始／恢复时注入密钥及模型连接快照；后台复核配置，仅在当前运行闭包持有密钥。等待问题、取消、结束及退出后释放引用，不声称 JavaScript 字符串能安全擦除。

密钥不进入 Settings、SQLite 业务记录、原文、checkpoint、模型输入、事件或 worker 配置。提供商错误只返回固定错误码／HTTP 状态，不保存原始响应错误、请求头或 SDK cause。没有钥匙串能力时，用户可明确选择桌面会话内存，不降级明文落盘。独立服务 CLI 没有钥匙串读取能力，`host.*` 前缀本身不是 OS 身份认证。

模型用量展示每轮、会话、托管和摘要调用的次数、输入／输出／总 token；缺失供应商用量标为不完整。模型设置的调用、token、费用提醒及每百万 token 单价均可留空。提醒不会授予或撤销执行许可；单轮仍有安全调用数和 HTTP 超时限制。价格估算不包含供应商未返回的用量，不作为账单。

## 原文、checkpoint 与记忆

| 记录                                          | 行为                                                                                                       |
| --------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| `agent_session`、`agent_message`              | 自动保存用户原文、完整 Responses 输出项和工具结果；函数调用 ID、`phase` 与不透明推理上下文保留             |
| `agent_checkpoint`、`agent_checkpoint_write`  | LangGraph 类型化 serde 保存 channel、parent、pending writes、taskPath 和待答中断；会话 ID 固定为 thread ID |
| `agent_memory`                                | 可查看、修改和删除的通用偏好／账号记忆；包含来源会话与消息 ID、时间及修订号                                |
| `agent_projection`、`agent_context_reference` | 模型上下文视图、成功校验的摘要及显式跨会话引用；不会覆盖原文                                               |

宿主复用账号识别的设备＋客户端＋配置账号标签范围。配置标签不是经游戏验证的 UID。所有会话读取、KV batch/search/list、memory、引用和恢复都校验宿主范围；切客户端或账号后，旧句柄不能绕过隔离。通用偏好单独保存，不能把账户库存写入通用偏好后当作实时事实。

近期完整对话、相关记忆、同范围的会话资料摘要和用户显式引用组成输入。完成的短对话可生成带消息 ID 的本机摘录；过长时先裁剪旧工具大结果的模型视图，保留调用 ID 和本机原文，再对完整旧轮次请求摘要，保留近期轮次和未完成工具调用。摘要模型用量计入同一账本；失败、取消、空输出或来源校验不通过时保留旧视图。原始输出项经过 JSON 序列化往返校验。

摘要、记忆和其他会话只提供信息。执行批准、额度、控制权与真实结果从业务记录重新读取，复制文字不能复制权限。

## 计划、目标、询问与审批

计划模式允许读取、提问和生成可编辑任务草稿。宿主工具白名单阻止执行、停止、外部 MCP 调用与视觉操作；模型伪造未提供的工具名也会被拒绝。目标模式可以申请动作，每个动作必须匹配批准的完整设备、客户端、任务／作业快照和扩展版本。切换模式本身不授予执行权。

`ask_user` 支持单选、多选和简短文本。持久交互队列区分普通问题、执行审批和外部 MCP 补充信息；普通回答不会被解释成批准。窗口关闭、未答或超时均不视为同意。等待时停止模型调用；重启后恢复卡片，用户显式恢复后才继续。执行草稿须通过既有编辑器检查保存，随后才能申请执行。

工具调用使用稳定调用 ID，派生固定 MAA requestId。持久 action 账本区分准备、已提交、已完成、等待外部补充和结果不明。重复投递返回原结果；结果不明时先核对业务请求账本，无证据则暂停人工核对，不换 ID 重放。快照、Skill 内容或 MCP 定义改变后，原批准失效。

药石默认零。只有有限次数的 Fight 可使用明确批准的数量，按完整启用任务的上限原子预留。缺少可信实际消耗时按批准上限占用，完成／失败／停止不会释放可能已消费部分。加急、临期药和无限作业用药持续拒绝。

有限托管保存固定目标、期限、最多执行次数和药石总额，先生成独立审批。业务完成事件或明确时间点唤醒确定性任务，不用模型持续轮询；失败、额度不足或快照变化暂停。应用重启后暂停，用户恢复时重新校验范围并读取关联任务／工具的持久结果，补足离线期间漏收的完成事件；结果无法核对时保持暂停，不重新提交。次数耗尽或授权到期仍可核对已有结果，不能新增执行。撤销阻止后续动作，已运行的原生任务须另行停止。

## Skill、MCP 与知识边界

文本 Skill 和双向 MCP 的设置、权限和协议限制见 [Agent 扩展](agent-extensions.md)。Skill 不执行脚本，不能增加权限；MCP 的只读自述不构成批准。MCP 服务端默认关闭，回环地址＋独立临时令牌提供查询和操作申请，实际动作仍进入 Maa Verge 的同一审批和账本。

当前知识资源及账号快照保持原有 JSON 查询接口。本轮只交付 [JSON/KV RAG 与知识图谱设计](agent-rag-design.md)，不声称模型已接入新检索、embedding、向量数据库或图数据库。

## 契约与验证

`packages/contracts/schemas/agent.schema.json` 定义会话、turn、交互、memory、上下文引用、托管、Skill、MCP 和凭据的参数／结果；`rpc.schema.json` 引用公开映射，另定义内部 `HostAgentRequest`。修改后运行 `pnpm contracts:generate`，生成 TypeScript 与独立校验器。启动立即返回 turn／operation ID，不将长模型调用或审批挂在桌面 RPC 上。

合成验证覆盖 Responses SSE 字节分片、UTF-8、事件边界、心跳、长生成、三种超时、失败／断流／取消、完整工具续轮、原样往返、错误脱敏及用量缺失，另有原文与摘要分离、类型化 checkpoint 重启恢复、账号隔离、答案与审批去重、快照变化、并发预留、未知结果核对、Skill 缩权和本机 MCP 协议。所有夹具使用隔离数据根或本机合成服务，无需游戏、MaaCore、付费请求或真实钥匙串。桌面验证只做行为断言；截图人工检查，不添加外观断言。平台实际钥匙串、真实供应商和真机执行需单独验收。
