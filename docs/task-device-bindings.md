# 任务表与设备绑定

任务表与设备是多对多关系：一张任务表可以绑定多台设备，一台设备也可以被多张任务表绑定。绑定保存的是可选执行范围，不是设备控制权；执行任务表、作业或工具时，设备仍只允许一个控制者。

## 保存绑定

在「任务 → 任务表详情 → 任务表设置 → 设备绑定」勾选设备，修改后自动保存。取消一项只解除这一项关系；「解除全部绑定」将任务表改为未绑定。切换底栏设备不会改变任务表绑定，离线设备和暂未发现的绑定仍会保留，可以明确取消。

绑定设置和运行窗口共用设备选择列表：按名称、地址或设备标识搜索，按全部、已选、在线、离线筛选；离线筛选包含未发现的绑定。列表限高滚动，名称、地址和状态分列展示，设备增多时不继续撑长页面。「选择筛选结果」「取消筛选结果」只修改当前筛选内可操作的设备，隐藏的选择仍然保留，汇总数量始终包含它们。绑定最多 100 台，达到上限后可继续搜索、查看和解绑。

运行窗口沿用相同的查找与选择方式，但只允许新增符合绑定范围且空闲的目标；已经选中的离线、缺失或冲突目标仍明确保留，可取消后继续。任务表列表只显示绑定总数和前两台设备，完整绑定在详情中管理。

未绑定的任务表允许在启动时临时选择任意设备；已经绑定的任务表只能选择绑定列表内的设备。删除历史设备记录不会解除绑定，也不会自动替换目标。

绑定设备共用本表的任务顺序、参数、客户端和账号设置；需要不同配置时请复制任务表。药剂、源石等消耗上限按每台设备的一次执行分别计算，多设备执行的总消耗可能累加。

## 开始与停止

任务表绑定多台设备时，「开始执行」打开设备选择窗口，可以执行其中一台或多台。勾选多张任务表后点击「运行」，可分别选择每张表的多个目标。启动选择不会改写保存的绑定。

任务表卡片的主按钮随执行状态切换：空闲时为「开始执行」，启动请求期间为不可重复点击的「正在启动…」，已有执行时为「查看执行」。查看执行只列出本表当前运行的设备，可通过「显示全部设备」返回完整监控。

已有执行时，通过更多菜单的「在其他设备执行…」打开设备选择窗口；没有其他空闲且符合范围的设备时，该入口禁用并显示「暂无可用设备」。已运行本表的设备只读显示「本表执行中」，不再默认勾选，也不能重复选择；已有绑定的追加执行默认只选择剩余可启动目标，未绑定表仍需明确选择临时目标。窗口打开后，已选目标在其他入口启动本表时也会从本次选择中排除。

首次开始时，绑定目标默认保留在选择中；离线、缺失或其他任务占用会明确提示，需要取消该目标或处理问题后再开始。同一设备被多张任务表同时选中时，窗口提示冲突，不会自行排队或替换设备。

每个「任务表＋设备」创建独立执行记录和启动快照。保存或解绑不修改正在执行的任务；一台设备停止或失败不影响其他设备。部分目标启动失败后，在同一窗口重试只提交失败的目标，不重复已成功启动的目标。

任务表列表汇总执行中的设备数；只有一台执行时显示「停止」，多台时明确显示「停止全部」，停止该表当前的全部执行。请求期间显示不可重复点击的「正在停止…」，执行终止后恢复开始入口。执行监控可按设备单独停止，并展示该设备绑定的全部任务表。设备绑定与历史执行归属分别保留，解绑不删除执行记录。

## 定时规则

每条每日定时固定一张任务表和一台设备，不会自动向整个绑定列表分发。可以为同一张表的不同设备分别建立规则。绑定表的定时目标必须在绑定列表内；解除其中一台设备后，只停用不再满足绑定范围的规则，其他规则保留。解除全部绑定后，任务表恢复允许任意目标，已经停用的规则仍需手动启用。

到点时读取已保存配置并复核目标，触发后固定本次任务快照。绑定范围改变导致规则失效时，尚在准备或倒计时的触发会取消；已经启动的运行继续使用原快照。同设备同刻只执行第一条，其余记录冲突跳过；不同设备独立执行。详见[工具箱与定时计划](toolbox-schedules.md)。

## 数据与接口

`Plan.deviceIds` 是绑定列表，元素唯一；显式空列表表示未绑定。旧 `Plan.deviceId` 继续兼容，读取旧数据时转换为零或一个元素，返回时对应列表第一项或 `null`。新客户端同时保存列表与兼容字段，列表为准；旧客户端省略列表且未改变兼容字段时，服务保留额外绑定。

任务表通过创建、编辑、执行和删除管理。旧 `Plan.enabled` 仅作协议兼容，服务读取与保存时统一为 `true`，历史值不影响执行。单项任务和每日定时仍各自控制启停；已停用的定时不会自动开启，已启用的定时按自身规则检查并执行。

`run.start` 仍明确提交 `planId`、`deviceId` 与独立 `requestId`，服务检查范围并取得设备独占。重试同一请求返回原执行，不因之后编辑绑定而重复执行。绑定不引入新的原生协议或设备控制路径。
