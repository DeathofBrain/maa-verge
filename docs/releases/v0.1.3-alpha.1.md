## Maa Verge v0.1.3-alpha.1

本次开发预览版集中更新任务中心、设备监控与作业库，并带来统一下载代理、应用更新续传和 Windows 完整离线安装包。

> **重要提示**：本版为预览版，升级前请备份配置与作业文件；macOS 最低支持版本提高到 15（Sequoia），Windows 停止提供 MSI。Windows 安装包仍无 Authenticode 发布者签名，macOS 采用 ad-hoc 签名、尚未完成 Developer ID 签名与公证；应用更新包的签名校验独立于系统发行签名。

### 升级说明

1. v0.1.1 / v0.1.2 的 EXE、macOS 与 AppImage 用户可在「设置 → 更新」将 Maa Verge 频道切为「预览版」后获取本版；旧 MSI 用户须备份后卸载旧版，再安装 EXE 或使用完整 ZIP，v0.1.0 与 Linux DEB / RPM 用户须手动更新。
2. 安装前完全退出旧版本，备份整个 `config/`、已有作业 JSON 目录与自定义组件文件；数据位置见[迁移与备份说明](https://github.com/DeathofBrain/maa-verge/blob/v0.1.3-alpha.1/docs/runtime-migration.md)。
3. 安装过未公开的 `v0.1.3-alpha1` 测试包时，请手动安装本版；按版本排序，`alpha.1` 低于 `alpha1`，应用不会自动降级。
4. 原下载器偏好不再使用，如需指定代理，请到「设置 → 更新 → 下载代理」选择手动 HTTP/HTTPS 代理并保存。
5. 选择「下次启动时更新」后需真正退出并重新打开应用，最小化到托盘不会触发安装；ZIP 版请退出并备份后手动更换文件，不使用 EXE 自动更新。

任务表统一从「任务」进入，勾选任务表后点击「运行」；设备进度在同页的「执行监控」中查看，底栏左侧可切换设备并打开运行详情、日志与画面。

### 已知问题与限制

- Agent 助手暂不可用，云模型、持续托管和视觉自主操作尚未开放。
- 作业干员标注依赖所选设备最近一次识别快照，绿色不代表技能、专精和模组等要求均已核验，缺失或未知数据需手动确认。
- 作业中心尚不支持社区账号、收藏 / 发布、作业编辑器及离线视频识别；普通多作业限同区域且整体单次，保全限单份，缺少明确战斗证据时仍显示通关未确认。
- MirrorChyan（Mirror酱）、纯 SOCKS / PAC 代理、下载缓存自动清理与应用内版本回滚尚未提供，VPN/TUN 继续依赖系统路由。
- 定时要求应用运行，错过的触发不补跑；Windows 可选唤醒受硬件和电源策略影响，macOS / Linux 不支持系统唤醒。
- 完整原 MAA 功能仍在补齐，真实游戏、多开、外服和各平台升级仍需对应环境验收；macOS 首次打开可能需要在系统设置中放行，详见[安装说明](https://github.com/DeathofBrain/maa-verge/blob/v0.1.3-alpha.1/docs/app-updates.md#macos-签名与首次放行)。

问题反馈：[提交 Issue](https://github.com/DeathofBrain/maa-verge/issues)，请提供应用版本、系统、MaaCore / 资源版本、复现步骤与脱敏诊断日志。

### 新增 | New

- 任务表支持多选运行与批量删除，单张任务表可选择多台空闲设备并行执行。
- 执行监控支持删除单个或批量离线历史设备，保留实例配置、任务表和执行记录。
- 社区作业搜索新增热度、最新和访问量排序，以及按关卡编号或名称补全筛选。
- 作业库新增分类、批量入队和确认删除，并可设置导入 JSON 的存放目录与删除偏好。
- 下载代理新增自动、手动 HTTP/HTTPS 代理与直连模式，应用、MaaCore 和游戏资源共用配置并显示下载速度。
- 应用更新包通过签名验证后持久保存，支持立即安装或下次启动时离线复核并安装。
- Windows EXE 新增 MaaCore 与 MaaResource 离线组件选项，并提供包含完整组件的免安装 ZIP。

### 改进 | Improved

- 任务中心整合任务表与执行监控，详情、连接设置和日志从抽屉打开，底栏按设备查看运行、日志与画面。
- 历史本机模拟器启动后可自动恢复连接，保留手动断开选择，恢复连接不会启动游戏或重放任务。
- 作业详情汇总干员要求、备选组和设备持有练度，关卡标识按当前资源显示为易读编号。
- 移除 aria2，三条更新通道统一使用内置 HTTP、断点续传与有限重连，自动代理失败时尝试直连。
- 首次启动在后台校验并准备随附组件，显示实时进度，期间可浏览页面和编辑任务。
- 统一下拉菜单、抽屉动画和弹层交互，兼顾深浅主题、键盘操作与减少动态效果设置。

### 修复 | Fix

- 修复模拟器关闭后设备仍显示在线，以及离线设备残留活动任务控制的问题。
- 修复弹层切换后页面无法点击，以及迟到的启动响应覆盖当前设备和历史记录的问题。
- 修复后台组件请求较慢时应用更新安装准备受阻，以及取消后遗留准备状态的问题。
- 修复部分干员职业形态缺少详细记录时，其他有效持有记录被一并丢弃的问题。
