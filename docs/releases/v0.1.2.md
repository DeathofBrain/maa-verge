## Maa Verge v0.1.2

本次正式版新增独立作业中心、每日定时、库存保持与公招计算，并带来任务表自动保存和右键菜单。

> **重要提示**：本版修复 v0.1.1 macOS 应用签名资源封装缺失导致的「应用已损坏」问题；macOS 仍未完成 Developer ID 签名与公证，首次打开可能需要在系统设置中明确放行，详见[安装说明](https://github.com/DeathofBrain/maa-verge/blob/v0.1.2/docs/app-updates.md#macos-签名与首次放行)。Windows 安装包仍无 Authenticode 发布者签名，应用更新包的签名校验独立于系统发行签名。

### 升级说明

1. v0.1.1 可在「设置 → 更新」下载本版；macOS 旧版无法启动时，直接安装对应架构的 DMG，v0.1.0 用户须手动安装。
2. 安装前完全退出旧版本并备份整个 `config/`，保留自定义组件和外部作业文件；数据位置与旧目录导入规则见[迁移与备份说明](https://github.com/DeathofBrain/maa-verge/blob/v0.1.2/docs/runtime-migration.md)。
3. 旧任务表中的作业任务可继续使用，也可显式复制到作业中心；新作业请从作业中心导入，定时规则请在已保存任务表的「定时计划」中设置。
4. Windows 建议沿用原来的 EXE 或 MSI 安装方式，Linux DEB / RPM 仍需通过安装包或包管理器手动更新。

### 已知问题与限制

* 完整原 MAA 功能仍在补齐，真实游戏、多开、外服及 macOS / Linux 游戏操作尚未完成实机验收；macOS 13.5 最低系统、下载核心后的签名加载及 Linux 托盘仍需目标机验证。
* 作业中心尚不支持社区账号、收藏 / 发布、作业编辑器及离线视频识别；普通多作业限同区域且整体单次，保全限单份，缺少明确战斗证据时显示通关未确认。
* 仓库与干员为带采集时间的识别快照，库存保持按识别及已确认掉落计算；小游戏核心流程结束不等于已确认获得游戏奖励。
* 定时要求应用运行，错过的触发不补跑；Windows 可选唤醒受硬件及电源策略影响，实际休眠恢复与定时游戏流程仍待验收，macOS / Linux 不支持系统唤醒。
* Agent 仍只生成本地规则提案，需审阅、保存后手动执行，云模型、视觉操作与自主托管尚未接入；公招加急、临期药及作业无上限用药仍受限。
* 应用更新下载仅保存在当前会话，暂不支持断点续传或应用内回滚；组件下载与回滚继续独立管理，MirrorChyan、下载缓存自动清理及多连接加速尚未接入。
* Windows 发布者签名、macOS Developer ID 签名与公证尚未完成，各平台真实升级安装仍需验证；结果截图来自核心缓存，日志分享前请检查个人信息。

问题反馈：[提交 Issue](https://github.com/DeathofBrain/maa-verge/issues)，请提供应用版本、系统、MaaCore / 资源版本、复现步骤与脱敏诊断日志。

### 新增 | New

* 新增独立作业中心，支持普通、保全及悖论作业的本地 JSON / PRTS Plus 导入、作业集预览、持久队列、编队设置与独立执行。
* 作业详情支持社区赞踩、默认关闭的通关后自动点赞，以及保留原始 JSON 和独立来源署名说明的导出。
* 工具箱新增公招计算、库存保持、数据管理与小游戏，仓库和干员识别改为独立工具执行并支持多格式导出。
* 新增每日定时计划、提前通知、忙时跳过与可取消的强制接管，并提供默认关闭的 Windows 提前唤醒选项。
* 任务表新增自动保存、失败重试及跨页草稿保留，开始执行前会等待当前配置保存完成。
* 任务表、任务队列、设备和执行记录等列表新增右键菜单，支持键盘操作及窗口边缘定位。
* 自动作战「指定材料」新增独立开关，关闭时保留已配置的材料与数量。

### 改进 | Improved

* 页面与连接失败优先显示具体中文原因和处理建议，保留原始诊断信息。
* 新建连接默认使用 MaaTouch，已保存的触控方式保持原值。
* 精简顶栏文案，优化工具箱留白、窄窗布局与干员头像展示。

### 修复 | Fix

* 修复 v0.1.1 macOS 应用缺少完整签名资源封装导致「应用已损坏」的问题。
* 修复组件已自动生效后再次点击启用出现误报，以及准备失败后界面状态未及时刷新的问题。
* 修复内置 HTTP 下载器的取消竞态，以及本地文件准备和写入被误判为网络停滞的问题。
