## Maa Verge v0.1.3

本次正式版更新任务中心、多设备执行监控与作业库，并带来统一下载代理、Mirror酱加速和完整安装包更新。

> **重要提示**：升级前请备份配置与作业文件；macOS 最低支持版本为 15（Sequoia），旧 macOS 客户端需手动安装一次新版 DMG。Windows 不再提供 MSI，Linux 不再提供 DEB / RPM。Windows 安装包尚无 Authenticode 发布者签名，macOS 采用 ad-hoc 签名、尚无 Developer ID 签名与公证；应用更新签名与系统发行签名分别管理。

Windows 使用 WebView2；EXE 默认勾选 MaaCore 与 MaaResource 离线组件，可按需取消，MaaResource 需同时选择 MaaCore。完整 ZIP 包含两者，完全解压到可写目录后运行 `Maa Verge.exe`，系统仍须具有 WebView2。首次启动会校验并导入随附组件，已有组件保持不变。未附带组件时，以及 macOS / Linux 首次使用时，需要联网下载核心和资源。

macOS 覆盖 Apple Silicon 和 Intel，最低支持 15；首次安装请从 DMG 将应用拖到「应用程序」，再按系统提示放行，详见[签名与首次打开](https://github.com/DeathofBrain/maa-verge/blob/v0.1.3/docs/app-updates.md#macos-签名与首次放行)。Linux 以 Ubuntu 22.04 / 24.04 x64 为目标，需要系统 WebKit / GTK 等桌面库及 AppImage 所需的 FUSE，其他发行版需自行确认依赖。

用户无需另装 Python、Node、Bun 或下载工具。Source code 为源码归档；`.sig` 和 `latest.json` 用于更新校验，首次安装请选择上表文件。macOS 应用内更新复用完整 DMG，不再提供专用更新归档。

### 升级说明

1. **先备份**：完全退出旧版本，备份整个 `config/`、已有作业 JSON 目录及自定义组件文件；数据位置与迁移规则见[迁移与备份说明](https://github.com/DeathofBrain/maa-verge/blob/v0.1.3/docs/runtime-migration.md)。
2. **Windows**：v0.1.1 / v0.1.2 / v0.1.3-alpha.1 的 EXE 用户可在「设置 → 更新」检查本版；旧 MSI 用户须先卸载旧版，再安装 EXE 或使用完整 ZIP。ZIP 版须退出、备份后手动更换文件，v0.1.0 用户须手动安装。
3. **macOS**：确认系统为 15 或更新版本；v0.1.2、v0.1.3-alpha.1 及更旧客户端仅支持旧更新归档，须从本页下载对应架构的 DMG 手动安装一次，之后使用新的签名 DMG 更新流程。
4. **Linux**：AppImage 用户可检查应用更新；旧 DEB / RPM 用户须保留配置并手动迁移至 AppImage。
5. **下载与安装设置**：原下载器偏好不再使用，如需代理，请在「设置 → 更新 → 下载代理」选择自动、手动 HTTP/HTTPS 代理或直连。选择「下次启动时更新」后须真正退出再打开，最小化到托盘不会安装。

任务表统一从「任务」进入，单表点击「开始执行」，或勾选多张表后点击「运行」；每张表可选择多个设备独立执行，进度在同页「执行监控」查看。停止会结束并清空当前原生队列，不支持暂停后续跑。默认理智药与源石预算为零，多设备执行会分别使用各次授权额度。

### 已知问题与限制

- **Agent 功能将于后续 v1.0.0 版本推出，敬请期待。** 当前版本暂不提供 AI 托管、云模型或视觉自主操作。
- **基建估算目前为草稿模块，更多、更全面的功能尚待开发。**
- 当前实机记录覆盖一个 Windows MuMu 实例的连接与增强截图；真实多开、雷电、不同游戏客户端及 macOS / Linux 的设备操作尚待分别验收，完整原 MAA 功能仍在补齐，PlayCover 与 Windows 原生游戏窗口尚未接入。
- MuMu / 雷电增强截图仅适用于受支持的 Windows SDK 与已核实实例，增强接口失败会报错，可手动改选 ADB；MuMu 增强触控仍为未实机验收的实验功能。
- 作业中心尚不支持社区账号、收藏 / 发布、作业编辑器及离线视频识别；普通多作业限同区域且整体单次，保全限单份，缺少明确战斗证据时显示通关未确认。干员标注依赖所选设备最近识别快照，绿色不代表所有技能、专精和模组要求均已核验。
- 仓库与干员为带采集时间的识别快照，库存保持依赖识别及已确认掉落；小游戏核心流程结束不代表已经获得游戏奖励。
- 定时要求应用运行，错过的触发不补跑；Windows 提前唤醒默认关闭，受硬件与电源策略影响，真实休眠恢复和定时游戏流程仍待验收，macOS / Linux 不支持系统唤醒。
- 应用内版本回滚、下载缓存自动清理及多连接下载尚未提供；Linux 桌面系统代理、PAC / WPAD 与纯 SOCKS 暂不解析，实际网络表现取决于环境。Mirror酱高速下载需要付费 CDK，官方免费来源继续保留。
- Windows 发布者签名、macOS Developer ID 签名与公证，以及最低系统、首次系统放行和三平台真实升级安装仍需验收；日志与结果截图分享前请检查个人信息。

问题反馈：[提交 Issue](https://github.com/DeathofBrain/maa-verge/issues)，请提供应用版本、系统、模拟器、MaaCore / 资源版本、复现步骤与脱敏日志。
