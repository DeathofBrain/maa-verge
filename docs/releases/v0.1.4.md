## Maa Verge v0.1.4

本次正式版加入持久 Agent 会话与审批托管，修正自动作战执行和结果同步，并消除任务间重复校验更新的提示。

> **重要提示**：升级前请备份配置与作业文件；macOS 最低支持 15（Sequoia）。Windows 安装包尚无 Authenticode 发布者签名，macOS 采用 ad-hoc 签名、尚无 Developer ID 签名与公证；应用更新签名与系统发行签名分别管理。

### 升级说明

1. 完全退出旧版本，备份整个 `config/`、已有作业 JSON 目录及自定义组件文件，详见[迁移与备份说明](https://github.com/DeathofBrain/maa-verge/blob/v0.1.4/docs/runtime-migration.md)。
2. v0.1.3 的 EXE、DMG 和 AppImage 用户可在「设置 → 更新」检查本版；完整 ZIP 需退出、备份后手动更换文件。macOS v0.1.2 / v0.1.3-alpha.1 及更旧客户端须手动安装一次本版 DMG；旧 MSI / DEB / RPM 用户需手动迁移至上表格式。
3. 使用 Agent 前，在「设置 → 模型连接」配置兼容 Responses API 的服务及凭据；计划模式用于查询与草稿，目标模式中的实际操作仍需审批，详见[Agent 使用与边界](https://github.com/DeathofBrain/maa-verge/blob/v0.1.4/docs/agent-integration.md)。

单份普通作业（包括剿灭）须在游戏内选好关卡和难度，从编队选择界面开始；普通多作业须处于受支持的同一区域地图页面，详见[自动战斗执行对照](https://github.com/DeathofBrain/maa-verge/blob/v0.1.4/docs/copilot-startup.md)。停止会结束并清空原生队列，不支持暂停后续跑；药石预算默认仍为零。

### 已知问题与限制

- Agent 已接入持久会话、审批和有限托管；自主解新关卡与视觉控制尚未开放，真实供应商、三平台系统凭据及设备执行仍需分别验收，模型调用费用由所配置的服务收取。
- 文本 Skill 不执行脚本；外部 MCP 需逐项启用和审批，当前未提供独立 MCP 密钥管理入口，旧协议实时询问不支持持久暂停，详见[扩展边界](https://github.com/DeathofBrain/maa-verge/blob/v0.1.4/docs/agent-extensions.md)。
- 普通多作业不支持跨区域导航与整体循环，保全仅支持单份；单份、循环或缺少明确结算证据时，通关结果保持未确认，作业编辑器、社区账号与离线视频识别仍未提供。
- 基建估算仍为草稿模块；识别结果为带采集时间的快照，干员绿色标注不代表所有技能、专精和模组要求已核验，完整原 MAA 功能仍在补齐。
- 本版 AVD 修复已有 macOS ModAVD 单实例的增强截图记录，其他模拟器、多开、不同游戏客户端及其他平台设备操作仍需分别验收；PlayCover 与 Windows 原生游戏窗口尚未接入。
- 定时需要应用运行，错过的触发不补跑；Windows 提前唤醒默认关闭，macOS / Linux 不支持系统唤醒，真实休眠恢复与定时游戏流程仍待验收。
- 应用内回滚、下载缓存自动清理及多连接下载尚未提供；Linux 桌面系统代理、PAC / WPAD 与纯 SOCKS 暂不解析，Mirror酱高速下载需要付费 CDK，官方免费来源继续保留。
- 最低系统、首次系统放行和三平台真实升级安装仍需验收；分享日志与结果截图前请检查个人信息。

问题反馈：[提交 Issue](https://github.com/DeathofBrain/maa-verge/issues)，请提供应用版本、系统、模拟器、MaaCore / 资源版本、复现步骤与脱敏日志。

<summary><b>v0.1.4（2026-11-04）更新内容</b></summary>

### 新增 | New

- 新增 Agent 持久会话、长期记忆、跨会话引用、计划与目标模式，以及可恢复的询问和执行审批。
- 新增 Agent 有限托管、模型用量展示与系统凭据存储，支持明确授权后运行已有任务表、工具和作业。
- 新增文本 Skills 管理和双向 MCP 接入，扩展调用共用执行审批与权限限制。
- 新增 MaaFwAdb 缺库检查与下载确认，下载完成后保存配置并重新连接即可启用。

### 改进 | Improved

- 普通作业队列按作业声明自动生成普通、突袭或两种条目，支持在队列内停止，并将结果集中显示在作业站与队列下方。
- 截图测试展示 MaaCore 本次截图回调报告的耗时，不再混入后续编码、传输与界面显示时间。

### 修复 | Fix

- 修复未声明、为零或无效难度的作业显示与入队行为，统一按普通处理。
- 修复 MaaCore 与资源更新在每项任务结束后反复校验的问题，改为所有设备上的整张任务表、整次自动作战及工具操作结束且核心空闲后统一校验并应用。
- 修复单份作业被误作地图队列执行的问题，单份剿灭与循环不再触发普通列表导航。
- 修复空干员要求及省略部署方向的合法作业被拒绝导入的问题。
- 修复战斗结算回调与队列选择同步，仅取消已确认成功的对应条目，保留失败和未确认项。
- 修复 AVD 模拟器地址大小写与传输登记问题，避免增强截图因连接串号不匹配而失效。
