# Maa Verge v0.1.0

首个开发预览版本。提供本地任务配置、执行、设备连接与组件更新；完整原 MAA 兼容仍在推进。

## 本版功能

- 主页仪表盘汇总设备、执行记录、活动日历与独立组件版本。
- 任务表支持重复任务、复制、排序、启停及逐项参数设置。消耗上限由启用的自动作战任务中的理智药与源石数量累计，默认均为零。
- 独立任务表执行页显示中文任务进度、材料累计、基建反馈、本机截图和只读实时画面；新记录保留启动时的任务快照。
- Windows 可发现已启动的 MuMu / 雷电实例，按实例保存连接与截图配置；多设备可分别开始、查看和停止执行。
- MaaCore 与游戏资源独立下载安装、验证及回滚，等待安全任务边界生效。下载目录可设置，安装版默认使用程序同级的 `MaaCore/` 和 `MaaResource/`。
- 游戏资源版本显示已安装包的活动名称与更新时间。官服与 B 服共用国服资源，外服使用各自元数据。
- Tauri 2 + React/TypeScript，独立 Bun 编译服务与 C++20 MaaCore worker。用户无需安装 Python、Node 或 Bun。

## 下载与首次运行

| 系统 | 架构 | 文件 |
| --- | --- | --- |
| Windows | x64 | `.exe`（NSIS）、`.msi` |
| macOS | Apple Silicon / arm64 | `_aarch64.dmg` |
| macOS | Intel / x64 | `_x64.dmg` |
| Linux | x64 | `.AppImage`、`.deb`、`.rpm` |

下载同页的 `SHA256SUMS.txt` 可核对安装包哈希。Windows 使用 WebView2；Linux 仍需要系统 WebView 和桌面库；macOS 最低目标为 13.5。首次启动按需下载 MaaCore 和基础资源；默认组件目录不可写时，在「设置 → 更新」选择可写目录后重试。连接已启动且开启 ADB 的模拟器，再手动开始任务。

GitHub Packages 同时提供安装包集合 [`ghcr.io/deathofbrain/maa-verge:0.1.0`](https://github.com/DeathofBrain/maa-verge/pkgs/container/maa-verge)，包含本页的全部安装包与校验文件。[提取方法](https://github.com/DeathofBrain/maa-verge/blob/v0.1.0/docs/packages.md)适用于已有 Docker 的环境。

当前 Windows 包未正式签名；macOS 包使用临时签名，未完成开发者签名与公证。系统可能提示无法验证发布者。

## 验证与已知限制

- 本版安装包由对应发布提交的 GitHub Actions 构建，包含 Windows x64、Linux x64、macOS arm64 / x64；构建通过不代表完成各平台的交互安装或真实账号验收。
- 本地 Windows x64 已通过完整工程检查、785 项 Bun 测试、274 项 Python 参考测试、4/4 CTest、Rust 检查，以及 69 项 Edge 界面回归；测试使用隔离数据与合成设备。详细范围见 [开发状态](https://github.com/DeathofBrain/maa-verge/blob/v0.1.0/docs/STATUS.md)。
- 真实连接和增强截图实测限已有 Windows 单个 MuMu；本版任务执行结果、真实多开、雷电、外服和其他平台的游戏操作仍待实机验收。
- 结果截图来自任务反馈后的核心缓存画面，不能保证是原始识别或结算图片。新执行才有逐任务结果，旧记录不补造。
- 定时调度、完整库存保持/同步、社区作业管理、模型自主托管及应用自动更新发布源尚未接入；Agent 仅生成本地规则提案。公招加急、临期药和无限用药等未完成消耗审计的选项仍受限。
