## Maa Verge v0.1.0

首个开发预览版本，提供本地任务配置、设备连接、执行记录与组件更新。

> **使用前请留意**
>
> 本版仍在开发预览阶段，完整原 MAA 兼容正在推进。Windows 安装包未正式签名，macOS 安装包使用临时签名、尚未公证；各平台交互安装和真实游戏任务仍有待验收。

### 本版亮点 | Highlights

#### 按任务表安排日常

任务可重复添加、复制、排序和单独启停，每项保留自己的参数。理智药与源石用量直接在自动作战任务中设置，默认均为零。主页汇总设备、执行记录和活动日历，任务配置从侧栏进入。

#### 在独立执行页查看进度与结果

开始后进入任务表执行页，查看中文任务进度、累计材料、基建反馈与本机截图，也可按需打开只读实时画面。执行记录保留启动时的任务快照，后续修改配置不改写历史。

#### 分别管理设备与组件

Windows 可发现已启动的 MuMu / 雷电实例，按实例保存连接与截图配置，多设备可分别开始和停止。MaaCore 与游戏资源独立下载、验证及回滚，更新等待安全任务边界生效；核心版本相同也会检查资源更新。

### 首次使用

1. 安装并启动 Maa Verge，等待按需下载 MaaCore 和基础资源。默认组件目录不可写时，在「设置 → 更新」选择可写目录后重试。
2. 启动模拟器并开启 ADB，在「设备」页发现并连接实例。
3. 新建或编辑任务表，核对任务参数与用药、源石数量，再手动开始执行。

### 已知问题与限制

* 定时调度、完整库存保持 / 同步、社区作业管理、模型自主托管及应用自动更新发布源尚未接入。Agent 当前仅生成本地规则提案，需审阅并手动执行。
* 公招加急、临期药和无限用药等选项仍受限。
* 真实连接与增强截图实测限已有 Windows 单个 MuMu。真实游戏任务、多开、雷电、外服及其他平台的游戏操作仍待实机验收。
* 结果截图取自任务反馈后的核心缓存画面，可能已进入后续流程。新执行才有逐任务结果，旧记录不补造。

遇到问题可[提交 Issue](https://github.com/DeathofBrain/maa-verge/issues)，说明应用版本、系统、MaaCore / 资源版本与复现步骤。

### 新增 | New

* 主页仪表盘：汇总设备、执行记录、活动日历与独立组件版本。
* 任务表：支持重复任务、复制、排序、启停及逐项参数设置，按启用的自动作战任务累计用药与源石上限，默认不使用理智药与源石。
* 独立执行页：展示中文任务进度、材料累计、基建反馈、本机截图与只读实时画面，执行记录保留启动快照。
* 设备管理：Windows 可发现已启动的 MuMu / 雷电实例，按实例保存连接与截图配置，多设备可分别开始、查看和停止执行。
* 组件更新：MaaCore 与游戏资源分别下载、验证、启用及回滚，等待安全任务边界生效；安装版默认下载到程序同级的 `MaaCore/`、`MaaResource/`，支持修改目录。
* 资源版本：显示已安装包的活动名称与更新时间，官服与 B 服共用国服资源，外服使用各自元数据。
* 自包含桌面安装包：内置 Bun 编译服务与 C++20 MaaCore worker，用户无需另装语言运行时。
