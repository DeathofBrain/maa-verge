# Release 说明

编写或修改本项目的版本说明时，使用 [maa-verge-release-notes 项目 skill](../../.skill/maa-verge-release-notes/SKILL.md)。写作规则与可复制模板统一在该 skill 中维护。

每版正文保存在 `docs/releases/<tag>.md`，本次候选为 [v0.1.3-alpha.1 预览版](v0.1.3-alpha.1.md)，当前正式版见 [v0.1.2](v0.1.2.md)，更早说明见 [v0.1.1](v0.1.1.md) 与 [v0.1.0 开发预览](v0.1.0.md)。本地修改不会自动更新已经发布的 GitHub Release。
