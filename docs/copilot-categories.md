# 本地作业分类

本地作业库的分类独立于普通／保全／悖论执行队列。分类支持新建、重命名、删除、为作业设置分类，以及在分页前按分类筛选；删除分类只将其中作业移至「未分类」，保留原始作业、执行队列、不可变版本与历史。

显式导入社区作业集时，成功选中的作业自动归入以作业集名称命名的分类。预览、未选择条目和失败条目不创建分类。相同来源作业集复用原分类，即使用户已将分类重命名；相同名称复用已有分类。再次提交同一导入预览保留用户对已有条目的手工分类，包括明确设为未分类的记录。再次预览后导入继续沿用原有新增本地条目的语义，不覆盖旧条目。删除分类后再次导入新条目可以重新创建分类。

分类保存为 `copilot_category` 实体，作业条目的可选 `categoryId` 只属于本地元数据。旧数据没有此字段仍可读取；明确清除分类写入 `null`。作业集来源映射使用独立的 `copilot_set_category` 记录，分类变更不修改原始 JSON 或来源署名。

类型化接口为 `copilot.category.list`、`copilot.category.save`、`copilot.category.delete`、`copilot.category.assign`。分类名限制 300 字符、去除首尾空白且不允许重名，最多 500 个分类；一次归类最多 100 个不同的本地作业，先验证全部条目与目标分类，再事务性保存。`copilot.list.categoryId` 缺省查询全部，`null` 查询未分类，字符串查询指定分类，筛选先于分页。

作业的显示关卡从当前活动资源的已安装关卡索引精确映射为关卡编号；未知、缺少地图文件或映射存在歧义时保留原 `stage_name`。预览、详情、本地列表与社区摘要使用相同映射，切换资源后从原始关卡标识重新计算显示；原始 JSON、执行用关卡标识及导出保持原值。
