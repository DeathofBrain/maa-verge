# 本地作业分类

本地作业库的分类独立于普通／保全／悖论执行队列。分类支持新建、重命名、删除、为作业设置分类，以及在分页前按分类筛选。右键分类可以删除，确认框默认仅删除分类、将其中作业保留为未分类，也可勾选同时删除分类中的全部作业。右键「全部」可删除整个作业库的作业，包含所有分类和分页，分类名称保留。

左侧本地作业卡片支持逐项选择、本页全选、半选和删除所选。全选只覆盖当前筛选后可见的作业；翻页、更换分类或修改搜索条件后清空选择。单份、所选、分类和全部删除均先显示确认框，执行队列和历史记录继续保留。

显式导入社区作业集时，成功选中的作业自动归入以作业集名称命名的分类。预览、未选择条目和失败条目不创建分类。相同来源作业集复用原分类，即使用户已将分类重命名；相同名称复用已有分类。再次提交同一导入预览保留用户对已有条目的手工分类，包括明确设为未分类的记录。再次预览后导入继续沿用原有新增本地条目的语义，不覆盖旧条目。删除分类后再次导入新条目可以重新创建分类。

分类保存为 `copilot_category` 实体，作业条目的可选 `categoryId` 只属于本地元数据。旧数据没有此字段仍可读取；明确清除分类写入 `null`。作业集来源映射使用独立的 `copilot_set_category` 记录，分类变更不修改原始 JSON 或来源署名。

类型化接口为 `copilot.category.list`、`copilot.category.save`、`copilot.category.delete`、`copilot.category.assign`。分类名限制 300 字符、去除首尾空白且不允许重名，最多 500 个分类；一次归类最多 100 个不同的本地作业，先验证全部条目与目标分类，再事务性保存。`copilot.list.categoryId` 缺省查询全部，`null` 查询未分类，字符串查询指定分类，筛选先于分页。`copilot.category.delete` 的可选 `deleteCopilots` 默认为 `false`；`true` 同时删除该分类全部作业。`copilot.delete` 互斥接受单个 `id`、一组 `ids` 或 `all: true`，删除结果返回 `deleted` 和 `deletedCount`。

「设置 → 数据与诊断 → 作业存储与删除」提供 JSON 目录和删除偏好。默认目录是程序目录的 `cache/copilot`，自定义目录需填写完整的绝对路径，留空恢复默认；`copilot.storage.info` 返回当前实际目录。目录变更用于后续导入，已有文件保留在原位置。设置保存在 `Settings.copilotStorage`，`directory` 默认空字符串、`deleteJsonFiles` 默认 `false`。

导入时应用在上述目录保存管理用的 JSON 副本。删除作业默认保留这些文件，启用「删除作业时同时删除 JSON 文件」后按记录的原位置清理；仍由其他库条目引用的共享文件保留。用户导入的原始文件不会被删除。运行、队列和历史使用独立的不可变版本，不随库条目的清理被删除或移动。

作业的显示关卡从当前活动资源的已安装关卡索引精确映射为关卡编号；未知、缺少地图文件或映射存在歧义时保留原 `stage_name`。预览、详情、本地列表与社区摘要使用相同映射，切换资源后从原始关卡标识重新计算显示；原始 JSON、执行用关卡标识及导出保持原值。
