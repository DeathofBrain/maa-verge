# 应用设置

「设置」集中管理外观、通知、更新、数据与诊断、外部服务和模型连接。可以搜索选项关键词，也可以从左侧分类进入；窄窗口使用横向分类栏。

模型连接、用量提醒、单价和 API 密钥由用户点击「保存配置」一起提交，输入、失焦、等待或切换分类不会自动保存。密钥留空时保留当前地址的已有凭据；更换地址不会迁移旧地址的密钥。保存失败保留输入以便重试，未提交的密钥仅保留在当前表单内存中。

其他偏好自动保存。开关和下拉选项立即保存，文字停止输入约半秒或离开输入框后保存；切换分类也会提交尚在等待的修改。页面显示保存状态，失败保留输入并提供重试。更新检查、安装、回滚、日志导出与删除仍由用户明确点击执行。

配置、作业 JSON、MaaCore 和游戏资源目录只能通过「选择文件夹」调用当前平台的系统目录窗口修改，不能手工输入。取消选择保持原值；选择成功或恢复默认目录后自动保存。Windows 使用系统文件夹窗口，macOS 使用系统目录面板，Linux 使用当前桌面支持的目录窗口。

配置目录变更在完全退出并重新打开后生效，不自动搬移旧数据；作业和组件目录仅用于后续导入或下载，已有文件、活动版本与回滚版本保持原引用。核心和资源目录位于各自更新卡片的「下载与安装目录」中。

Mirror酱 CDK 使用掩码输入，未保存值只保留在内存中；停止输入后自动保存到本机配置。其高速分发需要适用的付费 CDK，官方免费来源仍可使用。模型 API 密钥可明确选择系统凭据存储或仅本次桌面会话，不写入普通设置；模型接入及边界见 [Agent 产品接入](agent-integration.md)。

系统目录选择和真实通知仍需在各目标平台分别验收；浏览器夹具仅验证选择结果、取消、保存及失败恢复，不替代原生窗口验收。
