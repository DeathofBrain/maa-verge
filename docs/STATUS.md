# 开发状态

更新日期：2026-10-20。当前为 **0.1.0 开发预览**。工程和首批功能已落地，[PLAN.md](../PLAN.md) 中的完整产品与研究路线尚未全部交付。

## 已实现

| 范围 | 当前行为 |
| --- | --- |
| 工程与环境 | pnpm workspace、uv/Python 3.12、Cargo/rustup；版本文件、三个依赖锁、跨平台 bootstrap、doctor、AGENTS.md 和贡献说明 |
| 界面 | 中文总览、计划编辑、Agent 提案、执行记录、设置与更新；响应式布局、离线字体与本项目图形 |
| 通信与数据 | Tauri → Python 换行 JSON-RPC；Pydantic 输出 schema 生成 TypeScript；SQLite 保存计划、运行、设置和事件；请求去重、崩溃后不自动重放结果未知的执行 |
| Mock | 浏览器与桌面均可在无核心、无模拟器、无模型 Key 的情况下开发；明确显示模拟状态，支持运行、停止、提案审阅和更新流程 |
| 原生设备适配 | 显式 ADB 发现与连接；每设备独立 MaaCore 进程；异步连接、任务追加、开始、停止、回调归一化；同机共享设备锁 |
| 任务策略 | StartUp、Fight、Recruit、Infrast、Mall、Award、CloseDown；当前真实适配只支持官服；逐任务提交，校验成功证据及空闲状态后继续 |
| 首次安装 | 原生模式自动检查并下载官方稳定版核心；验证架构对应资产、版本、必需符号与资源加载后启用；核心和基础资源无需手动安装 |
| 核心更新 | 首次安装单独解压；已有安装在候选目录调用所保留的官方 Python `Updater.update()`，外层固定元数据、验证下载及安全解压，并独立校验结果；C API 本身无更新接口 |
| 资源更新 | 与核心独立；固定 MaaResource commit，同一提交查询及下载；从当前核心的基础资源重新构建候选，再应用当前完整覆盖快照，记录来源文件、提交、时间与内容哈希；移除上次覆盖的残留并保留基础任务与模型 |
| 更新切换 | 不可变版本目录；新进程校验；等待当前任务边界和异步调用结束后切换工作进程，保留后续任务；失败保留旧组合，可回滚上一组核心/资源 |
| 自动检查 | 原生模式启动时、核心每 24 小时、资源每 6 小时；失败五分钟后重试；下载与执行轮询分线程；关闭自动检查后支持手动操作 |
| 桌面生命周期 | 单实例、托盘、设置控制关窗行为、完全退出时关闭本地服务；开发默认 mock，安装版默认 native，可用环境变量覆盖 |
| CI | 应用检查及 Windows x64、Ubuntu x64、macOS arm64/x64 的未签名构建矩阵；具体结果以 GitHub Actions 为准 |

原生设备路径已实现，尚未通过真实账号的游戏操作验收。单独成功加载核心也不能证明所有关卡或任务语义兼容。

## 本机验证

宿主：Windows x64；Node 24.22.0、pnpm 10.20.0、Python 3.12.15、Rust 1.90.0。工具与虚拟环境保留在本机忽略目录，不提交至 Git。

- TypeScript 契约同步、前端类型检查与生产构建已通过。
- Python ruff、针对 linux/darwin/win32 的 mypy 检查与 73 项测试已通过。覆盖预算、请求去重、重启恢复、设备互斥、独立资源更新、任务边界切换、异步重连失败与超时恢复、归档别名、Windows 长路径和工作进程监督。
- Rust fmt/clippy/test 编译检查已通过；目前没有单独的 Rust 单元测试，不将编译检查计作业务测试。
- `pnpm check` 已完整通过：契约、前端类型、Python lint/类型/73 项测试及 Rust 检查。
- PyInstaller 打包服务的 stdio 快照、正常 EOF 退出及 frozen 辅助进程调用官方 Updater 的本地合成 ZIP 验证已通过。
- Windows 中文 MSI、NSIS EXE 完整构建已通过，输出位于 `apps/desktop/src-tauri/target/release/bundle/`。
- 7 项浏览器 mock 端到端测试已通过（默认 Chromium headless shell 及本机 Edge），覆盖计划持久化、提案审阅、停止、资源独立更新、任务中等待切换、错误反馈和窄屏导航；桌面及 390px 视口截图已检查。
- 官方在线元数据、实际下载与 Windows 原生加载验证通过：MaaCore **v6.20.0** 自动首装、MaaResource **d7ecff56c50e53424c787dfe435b565be50a586e** 独立安装与生效、回滚至基础资源；均由实际 MaaCore 隔离进程校验，未连接游戏设备。
- 归档测试覆盖 macOS 外目录和动态库文件别名；安全解压把合法文件别名物化为普通文件，拒绝越界及循环链接。macOS 最低目标按上游 MaaCore 设为 13.3。

本机未连接真实模拟器/安卓设备，也未调用付费模型。macOS/Linux 尚未在本机验收，CI 的配置不能替代平台实测。安装包尚未进行交互安装、签名或公证。

## 尚未实现及边界

- Agent 当前提供 **mock 规则提案**，供审阅、编辑和手动执行；真实模式的云模型、资料检索、自主托管、视觉工具和自动打新关卡尚未接入。
- 定时计划尚未实现；API 明确拒绝非空 schedule。界面只提供手动执行。
- 应用自身的自动更新发布源、签名和公证未配置；应用通道明确显示开发预览，核心和资源通道可独立使用。
- MirrorChyan、版本固定 UI、下载断点续传、旧版本自动清理及磁盘配额管理尚未接入。中断下载会记录失败并可重试，保留已启用版本。
- 当前热切换等待所有连接设备进入安全任务边界；尚未实现逐设备滚动切换。切换不迁移 MaaCore 战斗中上下文，不保证战斗中换核。
- 回滚恢复上一组核心/资源，不回滚业务数据库。资源加载自检通过不等于全部游戏行为验证通过。
- 尚无真实画面预览、掉落统计、库存同步和完整任务参数编辑。界面示意图不是设备截图，预算默认零。
- 资源 commit 与 last_updated 已记录，活动、公招和外服数据面板的独立刷新展示仍待完成。
- macOS 下载组件后的签名加载策略、Linux 系统托盘与最低系统兼容性仍需目标机验收。
