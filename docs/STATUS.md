## 尚未实现及边界

- Agent 当前提供 **mock 规则提案**，供审阅、编辑和手动执行；真实模式的云模型、资料检索、自主托管、视觉工具和自动打新关卡尚未接入。
- 定时计划页签已提供位置与状态说明，但调度服务尚未实现；API 仍明确拒绝非空 schedule。当前只可手动执行。
- 应用自身的自动更新发布源、签名和公证未配置；应用通道明确显示开发预览，核心和资源通道可独立使用。
- MirrorChyan、版本固定 UI、下载断点续传、旧版本自动清理及磁盘配额管理尚未接入。中断下载会记录失败并可重试，保留已启用版本。
- 当前热切换等待所有连接设备进入安全任务边界；尚未实现逐设备滚动切换。切换不迁移 MaaCore 战斗中上下文，不保证战斗中换核。
- 回滚恢复上一组核心/资源，不回滚业务数据库。资源加载自检通过不等于全部游戏行为验证通过。
- 作业中心目前索引任务表中的本地作业参数；工具箱可创建识别/只计算公招/已审核小游戏任务及查看、导出当前事件。尚无真实画面预览、掉落统计、库存保持/同步、专用识别结果导出、社区作业管理和全部上游选项的专用表单。常用字段可编辑，高级 JSON 可保留其他参数；不能据此声称 UI 工具和全任务语义已经完成。预算默认零。
- 任务表导入、空表保存、多选批量、可拖动分栏、密度选择、仅本次覆盖、失败策略及完成后系统动作仍待实现。任务表客户端由启动/关闭任务设置，尚无完整游戏档案层。
- 临期药、作业无上限用药、公招加急暂拒绝；任意 Custom 资源链尚未经过消耗策略审核，仅开放已审核入口。OperProgress 是消耗材料的养成任务，界面明确说明。完整兼容仍需补齐受限选项、定时、多配置、通知/远控、平台专用连接和 [功能矩阵](maa-compatibility.md) 中的各项验收。
- 自动连接仅对正在运行的本机模拟器发起连接，不启动模拟器/游戏，也不自动执行任务。非标准安装需配置路径；真实模拟器、外服资源和每类任务尚未实机验收。
- 资源 commit 与 last_updated 已记录，活动、公招和外服数据面板的独立刷新展示仍待完成。
