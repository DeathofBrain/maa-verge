# 作业声明的难度

难度标注采用 [MAA v6.20.0 作业协议](https://github.com/MaaAssistantArknights/MaaAssistantArknights/blob/v6.20.0/docs/zh-cn/protocol/copilot-schema.md) 中原始作业 JSON 的 `difficulty`，与执行队列的 `isRaid` 选择分别保存。

| 声明 | 含义 |
| --- | --- |
| 缺省或 `0` | 作者未设置支持难度 |
| `1` | 支持普通 |
| `2` | 支持突袭 |
| `3` | 普通、突袭均支持 |

`CopilotRecord.difficulty` 与社区摘要的 `CopilotSearchItem.difficulty` 均为可选元数据。仅接受上述数字；无效值不推断为普通、突袭或双难度，也不修改原始 JSON。旧作业记录读取时从已验证的不可变 JSON 恢复声明，不重写存储或用户已选的执行难度。缺少声明时不以标题、关卡编号、社区评分或本次执行选项推断支持范围。

普通社区搜索响应的 `content` 包含这一声明，可以直接解析。社区作业集摘要只有成员编号，没有作业集难度字段；作业集展示须使用已读取成员的声明。若将已知声明取并集，应说明这是集内已知成员的难度范围，不表示每一份成员作业均支持所有显示难度；加载失败和未知成员继续保留未知状态。

验证使用合成作业与社区响应，覆盖四种声明、缺省和无效值、旧元数据恢复、原始导出与执行难度不变。公开接口只作只读核查，未提交评价或操作真实设备。
