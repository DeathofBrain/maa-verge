# 作业声明的难度

难度标注采用 [MAA v6.20.0 作业协议](https://github.com/MaaAssistantArknights/MaaAssistantArknights/blob/v6.20.0/docs/zh-cn/protocol/copilot-schema.md) 中原始作业 JSON 的 `difficulty`，与执行队列的 `isRaid` 选择分别保存。

| 声明       | 含义                               |
| ---------- | ---------------------------------- |
| 缺省或 `0` | 作者未设置支持难度，产品按普通处理 |
| `1`        | 支持普通                           |
| `2`        | 支持突袭                           |
| `3`        | 普通、突袭均支持                   |

`CopilotRecord.difficulty` 与社区摘要的 `CopilotSearchItem.difficulty` 均为可选元数据，仅保存上述有效数字，不修改原始 JSON。旧作业记录读取时从已验证的不可变 JSON 恢复声明，不重写存储或用户已选的执行难度。缺省、`0` 或无效值统一按普通展示，新增队列项使用 `isRaid: false`；不根据标题、关卡编号或社区评分猜测突袭支持。

普通社区搜索响应的 `content` 包含这一声明，可以直接解析。社区作业集摘要只有成员编号，没有作业集难度字段；作业集展示使用已读取成员的声明，并将未声明难度的有效成员计入普通数量，同时注明按普通处理的成员数。角标表示集内存在对应难度的成员，不表示每一份成员均支持所有显示难度；加载失败的成员仍单独记录为无效，不计入普通数量。

验证使用合成作业与社区响应，覆盖四种声明、缺省和无效值、旧元数据恢复、原始导出与执行难度不变。公开接口只作只读核查，未提交评价或操作真实设备。
