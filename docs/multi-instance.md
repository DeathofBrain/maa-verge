# 模拟器多开

Maa Verge 可同时连接多个模拟器实例，并为每个设备保留独立的 MaaCore 工作进程、执行快照、进度、停止请求、识别时间和本机设备租约。此能力在单个 Maa Verge 窗口内使用，无需为每个模拟器另开一份应用。

## 使用方法

1. 在模拟器的多开管理器中启动所需实例，并开启 ADB。
2. 在「设备」页添加实例配置，分别保存名称、ADB 地址、连接/触控方式及截图配置。MuMu、雷电增强截图必须使用各实例对应的编号；可为不同实例选择不同安装目录和 ADB。
3. 连接各实例，在底部「多开执行」中分别选择任务表并开始。运行卡片可查看各实例进度、结果并单独停止。

保存独立实例清单后，自动连接只逐项尝试清单中的实例，失败单独显示并继续其他项；没有清单时沿用自动发现。单独“发现设备”仍可扫描本机候选。

同一张**未绑定设备**的任务表可以在不同实例同时执行。也可以复制任务表、分别绑定设备，保存不同账号的关卡、任务、预算与客户端。已绑定的表只会出现在对应实例的可执行选项中。编辑器顶部切换到另一个空闲设备后，也可启动同一张未绑定任务表。

## 配置与隔离

- 全局连接设置继续作为没有独立配置的设备的默认值。独立实例配置持久化在本机 `Settings.deviceProfiles`，按标准化地址选择对应连接/截图配置，不把全局增强截图编号套到所有实例。
- 每个实例只允许一个活动执行和一个控制者。同一 ADB serial、端口别名或同一 MuMu SDK 实例的桥接别名共享租约，不能用不同显示名称绕过排他控制。设备租约跨开发工作树和数据根共享。
- 多实例可同时提交同一任务表；每次启动单独保存参数快照和请求去重键，之后修改任务表不会改动已在执行的实例。
- 停止只发送到对应实例的 worker；其他实例继续。回调即使具有相同的原生任务 ID，也只影响其来源设备的当前执行。
- 不同客户端的基础/外服覆盖资源分别加载在各自进程中；外服覆盖缺失或加载失败会阻止连接。任务切换客户端时只在目标设备空闲后重建其 worker，保留连接时的 ADB、触控、SDK 和实例编号；其他设备的执行与停止不等待该次重连。停止或退出可取消尚未完成的切换。
- 消耗上限按**每次执行**分别检查，默认均为 0；在多个实例上重复执行带消耗的任务表，会分别使用各次授权额度。
- 运行详情和执行记录展示设备名；切换顶部设备会切换对应活动执行，截图与人工点击也按所选设备定位。

## 当前边界

目前管理的是已经启动、可通过 ADB 访问的模拟器实例；Maa Verge 不自动创建或启动模拟器。自动发现覆盖已有实现的本机地址，其他地址可手动配置。

核心和资源热更新仍等待所有活动设备到达安全边界，然后切换各 worker；不支持战斗中迁移上下文，也不提供逐设备滚动换核。

多开本身不要求 Windows 增强截图，普通 ADB 路径适用于 Windows/macOS/Linux。MuMu/雷电增强接口仍受 Windows、SDK、版本和实例编号限制。开发验证使用隔离的合成设备与 worker，真实多开模拟器、不同客户端及其他平台仍需分别验收；不能把合成通过视为账号操作已验证。
