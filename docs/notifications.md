# 系统通知

桌面应用在 Windows、macOS 和 Linux 使用系统通知。“设置 → 通知与远控”提供总开关和四类通知偏好，保存后立即生效：

- 执行结果：任务表、作业和独立工具执行结束、失败或中断。
- 设备异常：连接失败或连接丢失；连续失败只提醒一次，连接恢复后再次失败可重新提醒。
- 更新结果：应用或组件更新准备完成、组件生效及更新失败。应用、核心和资源分别处理。
- 定时提醒：提前通知和强制启动倒计时；提前通知仍需在定时计划中开启。

默认启用全部类别。关闭系统通知不会删除执行记录或关闭应用内提示。普通进度变化、历史快照和页面切换不会补发通知；执行结束不代表游戏通关或所有动作成功，具体证据仍以执行记录为准。

可在同一设置页检查并启用通知通道，或发送固定内容的测试通知。普通浏览器没有桌面通知入口；通知发送错误会明确反馈。系统通知设置、勿扰模式、桌面会话或通知服务可能影响投递，通道可用不代表通知一定展示。未收到测试通知时，在操作系统设置中允许 Maa Verge 通知；托盘驻留时应用仍能提交通知，完全退出后不会继续发送。

通知由桌面宿主消费实时事件并过滤、去重，偏好保存在业务设置的 `notifications` 字段。旧配置自动补默认值，旧客户端保存其他设置时保留通知偏好；原有定时通知也走同一总开关和分类开关。前端只能调用固定的状态查询和测试命令，不能指定任意通知消息。

常规测试使用隔离事件和桌面桥夹具，不向操作系统实际发送通知。三平台实际通知呈现仍需在各自桌面环境单独验收。
