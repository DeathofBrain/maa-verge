# 作业干员与本地练度标注

社区搜索卡片、本地作业卡片、导入预览和详情展示作业声明的干员。摘要把刚需干员与备选组放在同一排彩色标签中，只显示干员名或组名，不重复状态后缀。备选组默认收起，点击组名后展开最多三位候选，再次点击收起；同一份摘要只展开一组，键盘也可操作。先按作者顺序显示本地已拥有、全部声明要求均可确认满足的干员，再用已拥有且未发现明确练度不足的候选补足。悬停提示和详情保留完整状态，以及等级、专精、模组等待核验项，不宣称完全达标。明确未拥有、已知练度不足及持有未知者不进入备选摘要；没有候选时展开显示核对提示。详情保留全部备选、各自要求和「组内任选一位」语义。选择只影响展示，不修改作业内容或实际编队。

社区卡片从搜索响应已有的作业摘要提取干员，不逐份请求详情，也不隐式导入作业。解析与传输契约统一支持最多 2,000 条干员候选（包含全部备选组），避免把 104 条候选的正常作业误当成超量；原始内容、预览及通信大小仍受限制。摘要无效或不含干员信息时提示查看详情。

## 设备与颜色

使用 `recognition.get({ deviceId, kind: 'operators' })` 读取所选设备当前客户端的最近成功结果，不读取其他设备的名单。没有成功采集、读取失败或无匹配数据时保留原色；切设备与换号立即隔离旧数据，在途旧响应不能覆盖新设备。后续成功识别会刷新当前列表和详情。同一账号的后台重读保留已有展示。

页面分别提示未选设备、正在读取、读取失败和未采集。未采集时引导在工具箱执行「干员识别」；「仓库识别」仅更新材料。名单缺项与同名歧义在悬停提示和详情中说明「未核验」，摘要标签保持原色。MaaCore 按名称给所有职业形态标记持有，但详细名单可能只含一个形态 ID；解析时跳过缺少详细记录的持有形态，不再连带丢弃其他有效的 `own: false` 记录。旧快照中已经丢失的记录需重新识别才能补齐。

| 颜色 | 含义 |
| --- | --- |
| 绿色 | 已有明确的 `own: true` 记录，已知练度没有发现不足；不代表所有要求已核验 |
| 红色 | 有明确的 `own: false` 记录 |
| 黄色 | 已拥有，但明确识别的精英化、等级或潜能低于作业要求 |
| 原色 | 未采集、未匹配或匹配存在歧义，不能据此断言未拥有 |

备选组标签按整组候选判断：存在已拥有且无已知不足的候选时为绿色；没有可展示候选但仍有持有未知者时保留原色；其余已知候选中存在练度不足时为黄色，全部明确未拥有时为红色。绿色仍不代表专精、模组等全部核验，相关说明保留在悬停与详情中。

识别结果可能只有部分名单，所以「未在名单找到」不等同于「未拥有」。先按唯一名称匹配；名称不一致时按已安装资源的各服别名解析唯一干员 ID，名称或 ID 仍不确定则保留原色。资源查询共用头像缓存并只在可见区域按需读取。头像星级原色在没有持有状态时保留。

精英化升级会重置等级：精二 1 级满足精一 70 级要求，不能只比较等级数字。负数识别值属于未知，不作为不足证据。当前 OperBox 持久结果没有技能等级、专精或模组字段，详情明确提示这些要求需要手动核对，不虚构已达标或不足。作业元数据只声明名字，无法由部分识别名单证明同名干员的具体职业形态，也需手动核对。数据采集时间显示在详情中；标注只提供参考，不改变编队、执行或消耗策略。

## 社区术语

按 [MAA v6.20.0 作业协议](https://github.com/MaaAssistantArknights/MaaAssistantArknights/blob/v6.20.0/docs/zh-cn/protocol/copilot-schema.md) 解释数值字段，保留原始 JSON。

| 字段 | 展示 |
| --- | --- |
| `elite: 0 / 1 / 2` | 精零／精一／精二 |
| `skill: 1 / 2 / 3` | 技能 1／2／3，表示使用的技能序号 |
| `skill_level: 1..7` | 技能 1～7 级 |
| `skill_level: 8 / 9 / 10` | 专一／专二／专三 |
| `module: 0` | 不使用模组 |
| `module: 1 / 2 / 3 / 4 / 5` | X／Y／A／D／B 模（χ／γ／α／Δ／β） |
| `module_level` | 模组等级，与模组类型分开显示 |
| `potentiality`（兼容 `potential`） | 潜能要求，参与本地潜能比较；同时声明时取较高值 |
| 负数要求 | 不作要求，不展示成实际等级 |

尚未识别的扩展数值要求保留字段名，不猜测含义。界面与接口回归使用合成社区、干员和设备，不操作真实账号；原生 WebView、其他平台及真实识别仍按对应环境单独验收。
